# Tech Stack

## Overview

Call Sheet is a **web-platform-first, static** daily game. The runtime is plain
HTML, modern CSS, and vanilla JavaScript (ES modules) enhanced with **Lit** Web
Components. There is **no server runtime** — the daily puzzle is precomputed
static JSON, player state lives in `localStorage`, and the whole site deploys as
static files to Dreamhost shared hosting. Node is used only as a build-time tool
(Vite + the TMDB curation script), never in production.

## Core Technologies

### Language

**Primary**: JavaScript (ES2022+ modules); TypeScript optional via JSDoc/`.ts` if desired later
**Version**: ECMAScript 2022+

### Framework

**Framework**: Lit (Web Components)
**Version**: ^3.x
**Rationale**: Tiny (~5KB), standards-based Web Components with reactive rendering and templating. Complements the web platform instead of replacing it.

### Runtime

**Runtime**: The browser (no server runtime). Node.js for build/tooling only.
**Version**: Node.js 20+ (build/dev only)

## Data Layer

### Database

**Type**: Static files (no database)
**Database**: Precomputed per-day puzzle JSON files served as static assets
**Version**: n/a

### ORM / Data Access

**Tool**: None — `fetch()` of static JSON; client reads/writes `localStorage`
**Rationale**: Web-platform-first; no backend means no ORM

### Caching

**Solution**: HTTP/browser caching of static assets; TMDB responses cached at build time by the curation script

## API Layer

### API Style

**Style**: No runtime API. Build-time integration with the TMDB REST API (offline script)

### Documentation

**Tool**: Markdown — document the puzzle-JSON schema in the repo

## Frontend (if applicable)
