## Applied Suggestions

### 1. [Accessibility] Drop incomplete ARIA grid roles; enrich live announcements

- **File**: `src/components/call-sheet-board.js`
- **Description**: The column headers were marked `role="row"` / `role="columnheader"`
  without an enclosing `role="grid"`/`table` ancestor. Because all 12 chips render
  in a single flat list (required for stable FLIP identity), there is no real
  per-column DOM grouping for assistive tech to traverse — so the table roles
  asserted a structure that isn't actually present.
- **Rationale**: Prefer honest semantics. Headers are now plain labelled text; the
  `aria-live="polite"` status line carries the interaction meaning, and the
  selection announcement now names the actor's group ("Selected … from Group n.
  Choose a cell to swap with."), which is more useful to screen-reader users doing
  select-then-swap than a static columnheader role.
- **Risk Level**: Low (no behavioural change; tests updated to match)
- **Approved**: 2026-06-14T12:03:00Z
- **Diff**:

```diff
- <div class="headers" role="row">
-   <div class="head g${c} ${solved ? 'solved' : ''}" role="columnheader">
+ <div class="headers">
+   <div class="head g${c} ${solved ? 'solved' : ''}">

- this._announce = `Selected ${name}. Choose a cell to swap with.`;
+ const group = this._columnOf(actorId) + 1;
```
